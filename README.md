### Cristian Desivo

Mathematician and AI engineer. Since 2016 I've taken projects from a set of requirements to a
working system on my own: modeling the problem, building the data and models, writing the code
and delivering it.

**What I work on**

- **Mathematical optimization**: container loading, production scheduling, operations research,
  non-linear optimization, metaheuristics.
- **LLM systems**: retrieval, agents and structured outputs,
  systems bounded to approved content.
- **Deep learning**: datasets, training and deployment, mostly computer vision. Local LLM
  inference with llama.cpp, vLLM and Ollama.
- **Games**: [Pixel P.I.](https://store.steampowered.com/app/2448910/Pixel_PI/), a detective game
  on Steam where you type your own questions to suspects, and
  [Murder in the Aethertree Forest](https://crischu.itch.io/murder-in-the-aethertree-forest),
  a visual novel made in a month for a jam.
